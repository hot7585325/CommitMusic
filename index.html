如何將真實專案轉換？

在任何 Git 專案執行：
git log --reverse --pretty=format:"COMMIT:%h|%an|%s" --numstat > gitlog.txt 然後點擊右上角「匯入 Git Log 檔案」即可生成！

表格即是編曲機

您可以直接在表格的 o 或 _ 格子上點擊，自由增加或消除音符。右側也可以更換每軌的樂器與音高。

防走音五聲音階 (Pentatonic)

預設鎖定為大調/小調五聲音階（C, D, E, G, A）。不管同一次提交同時更動了多少個檔案，合奏時保證聽感和諧不刺耳！
